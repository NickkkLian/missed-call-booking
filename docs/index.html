Callback DeskTurn missed calls into bookings — staff approve every message and every calendar write. Demo · fictional customers · dry run GitHub
About this demo
Fictional customers (Test Customer 01), phone numbers only from the reserved 555-01xx test range, 123 Example Road; postal codes K1A 0B1 / H0H 0H0 are public format examples that may be assigned in the real world. Every send and calendar write is simulated and labelled so. Apart from its web fonts (Google Fonts), the page makes no network requests.
Not verified here
Import into a running n8n instance · provider adapters (SMS, WhatsApp, calendar) are placeholders · static data has no concurrency, crash recovery or durable opt-outs · no geocoding, availability solver, cancellation/rescheduling or emergency triage · provider signature verification is not implemented. The 22 scenarios are replayed in this tab; that proves the state machine, not the runtime.
